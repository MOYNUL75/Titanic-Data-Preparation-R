# Titanic Data Preparation and Analysis in R

This project focuses on the comprehensive preparation and univariate analysis of the Titanic dataset using R. It includes steps for handling missing, noisy, and invalid data, along with visualizations to derive insights and prepare the data for further machine learning tasks.

## 📊 Dataset Overview

The dataset includes the following variables:

- `gender`: Passenger gender (`male`, `female`)
- `age`: Age in years (integer)
- `sibsp`: Number of siblings/spouses aboard
- `parch`: Number of parents/children aboard
- `fare`: Ticket fare (numeric)
- `embarked`: Port of embarkation (`C`, `Q`, `S`)
- `class`: Travel class (`First`, `Second`, `Third`)
- `who`: Passenger type (`man`, `woman`, `child`)
- `alone`: Whether the passenger was alone (`TRUE`, `FALSE`)
- `survived`: Survival status (`0` = did not survive, `1` = survived)

## 🧪 Project Objectives

- Identify and fix missing, invalid, or inconsistent data
- Normalize numerical data and convert to categorical where needed
- Use R visualizations (boxplots, bar charts) for EDA
- Prepare a clean dataset for future ML applications

## 🛠️ Tools and Packages Used
